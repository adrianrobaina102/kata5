====================================================
RUTAS DE PRUEBA - KATA 5 (ITERATION 2)
====================================================

1) PETICIONES AL BALANCEADOR (NGINX - Puerto 8080)
----------------------------------------------------
- Distancia:
  http://localhost:8080/api/v1/distance/?km=10

- Temperatura:
  http://localhost:8080/api/v1/temperature/?c=25


2) CONSUL (Puerto 8500)
----------------------------------------------------
- Interfaz web (UI):
  http://localhost:8500

- Ver réplicas registradas de cada servicio:
  http://localhost:8500/v1/health/service/distance_service_v1
  http://localhost:8500/v1/health/service/temperature_service_v1


3) ARGUMENTOS DE ARRANQUE POR RÉPLICA (ID host puerto consul)
----------------------------------------------------
- Distance:
  d1 localhost 8081 http://localhost:8500
  d2 localhost 8082 http://localhost:8500

- Temperature:
  t1 localhost 8083 http://localhost:8500
  t2 localhost 8084 http://localhost:8500


4) COMANDOS ÚTILES (desde load-balancer/)
----------------------------------------------------
- Levantar Consul + NGINX:
  docker compose up -d --wait

- Recargar NGINX tras cambios de configuración:
  docker compose restart nginx
